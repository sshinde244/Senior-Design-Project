About this project

Claude + MCP + Ollama

This workspace demonstrates two AI paths in one interface: hosted Claude with MCP tool access and local Ollama-based chat, both inside the same frontend.

What is this?

This is a fullstack Node.js application that lets Claude call external data APIs through MCP and also provides a separate local chat workflow through Ollama.

The hosted side handles live tool use with agentic MCP flows. The local side gives you direct model access and can optionally share the same MCP menu depending on your backend setup.

The result is one workspace for comparing hosted and local AI experiences without switching interfaces.

Node.js Express Anthropic SDK Claude Agent SDK MCP (stdio) Ollama TMDB API US Census API

How a request flows

1
You choose a chat mode Use Claude for hosted MCP-powered responses or Ollama for local model interaction.
2
The frontend sends your message Requests go to the Express backend with conversation history and any selected MCP or model settings.
3
Backend routes the request Claude requests can use agentic MCP calls, while Ollama requests go to your local model endpoint.
4
You get a response in the same UI Each chat mode keeps its own tab history and interface while sharing the same visual workspace.

API Reference
MCP Guide

Endpoints

MethodPathDescription
GET /api/mcpsReturns list of registered MCP servers with id and label
POST /api/agentClaude agent route with selected MCP
POST /api/ollamaLocal Ollama chat route with selected model and optional MCP
GET /api/ollama/modelsReturns available Ollama models

Chat API

The main hosted flow uses Claude through the agent endpoint rather than a plain no-tool chat in this frontend.

Agent API

Claude requests use the selected MCP server and return a synthesized answer, plus metadata about which MCP was selected.

POST /api/agent { "message": "What are the top trending movies this week?", "history": [], "mcpId": "tmdb" }

Ollama API

Ollama requests send the chosen local model, conversation history, and optional MCP selection through a separate local-model route.

POST /api/ollama { "message": "Summarize today's headlines", "history": [], "model": "qwen2.5", "mcpId": "news" }

MCP Configuration

All MCP servers are registered in your backend config and loaded into both dropdowns in the frontend.

Adding a New MCP

Add the MCP in the backend registry, restart the server, and it will appear in both the Claude and Ollama selectors when the frontend reloads.
